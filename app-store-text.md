## Promotional Text
Create scoreboards for games and sports. Start from templates, customize scoring buttons, track history, undo mistakes, and easily rename scoreboards on the fly!

## Description
Scorr is a fast, flexible scorekeeper for game night, pickup sports, classroom activities, trivia, tournaments, and custom scoring.

Start from a built-in template or create your own scoreboard from scratch. Add players or teams, choose how winners are tracked, and update scores with quick tap controls. Scorr keeps scoring clear and readable so everyone can stay focused on the game.

Built-in templates help you get started quickly for board games, card games, trivia, basketball, football, soccer, volleyball, pickleball, tennis, baseball, golf, bowling, darts, cornhole, and more.

Features:

- Create scoreboards for games, sports, counters, and custom activities
- Use quick-start templates or build a scoreboard from scratch
- Add, remove, and rename players or teams
- Track highest-score-wins, lowest-score-wins, or no-winner scoreboards
- Use custom scoring increments for different games
- Undo score changes when someone taps the wrong button
- Review score history to see how the game changed over time
- Save reusable templates for favorite scoring setups
- Share final scores with friends, players, or teammates
- Continue recent scoreboards from the home screen
- Use portrait or landscape layouts

Scorr is useful for board games, card games, family games, party games, sports, classroom point tracking, challenges, practices, and any activity where keeping score should be simple.

Open Scorr, pick a template, add players, and start scoring.

## Review Notes
Scorr is a scorekeeping utility. The main flow is:

1. Open the app.
2. Choose a quick-start template or tap + to create a new scoreboard.
3. Add or rename players/teams.
4. Start the scoreboard.
5. Tap score controls to update points.
6. Use the menu to view history, share scores, save a template, or end the game.

No reviewer account is required for the core app experience.
