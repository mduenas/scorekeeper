## Short Description

## Full Description
Scorr is a simple, flexible scorekeeper for game night, pickup sports, classroom activities, trivia, tournaments, and anything else that needs a clean scoreboard.

Start from a built-in template or create your own scoreboard from scratch. Track scores for one player, two teams, or a larger group, then update points with quick tap controls. Scorr keeps the scoreboard clear, fast, and easy to read so you can focus on the game instead of the math.

Built-in templates help you get started quickly for board games, card games, trivia, basketball, football, soccer, volleyball, pickleball, tennis, baseball, golf, bowling, darts, cornhole, and more.

Key features:

- Create scoreboards for games, sports, counters, and custom activities
- Use quick-start templates or build a scoreboard from scratch
- Add, remove, and rename players or teams
- Track highest-score-wins, lowest-score-wins, or no-winner scoreboards
- Use custom scoring increments for different games
- Undo score changes when someone taps the wrong button
- Review score history to see how the game changed over time
- Save reusable templates for your favorite scoring setups
- Share final scores with friends, players, or teammates
- Continue recent scoreboards from the home screen
- Works well in portrait and landscape layouts

Scorr is useful for board games, card games, family games, party games, sports, classroom point tracking, challenges, practices, and any activity where keeping score should be easy.

No more hunting for paper, calculators, or a notes app. Open Scorr, pick a template, add players, and start scoring.
